02

Practical AI Training.

This training is designed so participants can start using generative AI safely in real work. It covers tool differences, prompt writing, information handling, internal rules, and hands-on business examples.

Starter course

For first-time users. Learn the differences between ChatGPT, Copilot, Gemini, and Claude, what AI can and cannot do, and how to use prompts safely.

Executive course

For managers and decision makers. Learn how to evaluate AI adoption, set usage policies, prevent information leakage, and calculate business impact.

Practical Copilot course

For business users. Practice Outlook, Word, Excel, Teams, PowerPoint, SharePoint, and daily workflows using Copilot and AI assistants.

03

Security Training.

Information security basics

Password management, phishing prevention, information leakage prevention, and everyday security behavior for all employees.

Targeted attack and ransomware readiness

Understand current attack patterns and the practical response steps organizations need before an incident occurs.

Incident response drills

Practice the flow from first response to escalation, reporting, containment, and recovery.

Security for generative AI

Define AI usage rules, protect confidential information, and build safe guidelines for AI tools in business.

04

Microsoft Training.

Microsoft 365

Teams, SharePoint, OneDrive, Power Automate, and collaboration workflows that improve daily productivity.

Microsoft Copilot

Use Copilot in Word, Excel, PowerPoint, Outlook, and Teams to improve document creation, meetings, and communication.

Azure fundamentals

Learn the basic concepts required to understand cloud services and AI implementation on Azure.

Microsoft security

Practical training using Microsoft Defender, Entra ID, Intune, and security administration concepts.
